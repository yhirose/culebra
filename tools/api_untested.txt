# Ratchet for tools/check_api_coverage.sh.
#
# Each line names a namespace function (`Ns.fn`, from docs/quick-guide.md's
# generated signature index) or a grammar keyword (from include/grammar_def.h)
# that no tests/*.cul, tests/*.sh or executed doctest block ever calls.
#
# The check FAILS on such a name that is NOT listed here (documented but
# never exercised), and on a listed name that HAS since gained a durable
# caller (shrink the file — `--update` does it).
#
# Blank lines and `#` comments are ignored, and a name is the whole line. Put
# the reason for an entry in a comment *above* it, the way
# tools/difftest/leak_abort_allow.txt does.
#
# An entry is a backlog item, not a decision: it says a documented rule has
# no durable caller yet, not that it is fine to leave that way. `FS.abspath`
# and `Http.put`/`delete`/`head` sat in this position across two releases
# before docs/essays/one-front-end.md's coverage audit found them — this file
# exists so the next one shows up here instead of by accident.
