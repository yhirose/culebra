# Allowlist for the release-to-release differential (release_diff.sh).
#
# Each non-comment line names a case whose behaviour differs between the
# previous release's binary and this build. `*` and `?` are the only
# wildcards — a label is a fragment of culebra source, so brackets and braces
# in it are literal. The gate FAILS on any difference NOT matched here (an
# unintended change); a listed pattern that matches nothing is reported so
# this file can shrink once the release that needed it has shipped. Blank
# lines and `#` comments are ignored.
#
# Put the "why" in a comment above the entry, the way leak_abort_allow.txt
# does. This file is the draft of the next release's notes: an entry is a
# change someone decided to make, and one with no reason attached is a change
# nobody did.
#
# `unsupported` on the baseline side means the older binary could not even
# parse the case — syntax that release predates.

# A range's endpoints may be Float: the baseline refused `0.0..0.86` and
# `Range(nil, 0.86)` where they were built, and named only Long in the
# endpoint TypeError. Iteration, slicing and grid still require Long.
range_float|*

# `r.contains(x)` on a range is new: the baseline had no such method on a
# range and raised a call on nil.
range_contains|*

# Range patterns (`..0.01 =>`, `0..10 =>`) and negative literal patterns
# (`-1 =>`) are new syntax: the baseline cannot parse these cases.
match_range|*

# `s.words()` and `s.sentences()` (UAX #29 segmentation) are new since
# v0.4.0: the baseline answers each case as an unknown member where this
# build answers as a built-in, and a bare read of either name is now the
# built-in-method diagnostic where the baseline read nil.
m|*|words|*
m|*|sentences|*
bareread|*|words
bareread|*|sentences

# `Math.f32` joined the namespace after v0.4.0, so `Math` has one more member
# than the baseline binary's: every case that asks a namespace object for its
# size reads 25 where the baseline read 24. The shadowing these cases are
# about is unchanged — the built-in `size()` wins in both, and only the
# number it answers with moved.
ufcsshadow|size|*|Math
ufcsshadownest|size|*|Math
ufcsshadowform|size|*|Math

# A class's scalar declared field type is checked on every write now
# (docs/language.md §10); it was documentation in v0.4.0. A case that writes
# the wrong kind into a declared `Long` gets the TypeError the annotation
# promises where the baseline took the value.
field-forward-read

# An instance's class/enum tag stops being one of its own fields (52b5ac8c):
# identity now reads the meta directly instead of a `class`/`__enum` slot the
# instance quietly carried. `type_of()` and printing answer the real class or
# enum name where the baseline could only ever say "Object" for the tag it
# never looked past.
#
# An enum variant also prints the way it is written now, `E.V(1)` and `E.W`,
# where the baseline printed it as a class instance (`V {mut _0: 1}`, `W {}`).
ctor-enum|*
ctor-class|*
ctor-call|*
ctor-enum-nullary
selflex|*

# The same commit drops that slot from an instance's own-field count, so
# `Sc.new().size()` — an own-field count — reads one lower. `size` is the only
# name in the UFCS-shadow sweep whose builtin answer depends on field count,
# and `Sc.new()` is the sweep's only class instance.
ufcsshadow|size|*|Sc.new()
ufcsshadownest|size|*|Sc.new()

# `.layer_norm(gamma, beta)` (fused layer norm over a Tensor's last axis) is
# new since v0.5.0, the same two-way difference as causal_attention above.

bareread|*|layer_norm

# `x.drop()` with no arguments is the at-most-once guard for an instance only.
# What a declaration binds — a class object, an enum's, a namespace — stands
# outside the instance protocol, so `drop` there is a member name like any
# other: a static `drop` is called (the baseline answered nil without calling
# it), and one that is not there is the error any missing member gives —
# `Math.drop()` is an AttributeError where the baseline answered nil.
ufcsshadow|drop|*|Math
ufcsshadownest|drop|*|Math
ufcsshadowform|drop|*|Math

# A free function is a UFCS candidate only when its first parameter accepts
# the receiver (docs/language.md §10, issue #23). `"x".f(1)` against
# `f = fn (n: Long, m: Long)` is the ordinary method miss now — "expected
# Function, got Nil" at the receiver — where the baseline called `f` anyway and
# reported its parameter 'n' at the method name.
typos|let f = fn (n: Long, m: Long) { n }; "x".f(1)
typos|let f = fn (n: Long, m: Long) { n }; "x".f(m: 1)
