# The gate measures under GC_NEVER, which cannot tell a reference cycle from
# a retain that is never dropped: both read as growth. The one diagnostic
# that separates them is cutting a single edge in the program (nil the
# field, reassign the binding): a cycle's growth falls to 0, a leaked
# retain's does not. Classify a new entry that way before filing it below.
#

# benign cycles). These entries stay; a "no longer leaks" report for one
# means the corpus or the collector changed, which is worth looking at
# either way.

# A reassignable self-recursive binding needs its cell: the closure holds

# Mutually recursive `fn` declarations: each dispatcher cell holds the other's
# body, so the pair is a ring wherever it is written. The effect-body twin
# measures the same as the plain one (a `fn ev` / `fn od` pair nested in an
# ordinary fn, 360 on the executor), which is what says the transform did not
# add it — a self-recursive `fn` in the same position is 0.
jit	eff|effect fn a(); effect fn f() { let b = perform a(); fn ev(n) { if n == 0 { return b }; od(n - 1) }; fn od(n) { if n == 0 { return b + 1 }; ev(n - 1) }; to_string([ev(4), od(4)]) }; handle { f() } with a(k) { k(100) }
vm	eff|effect fn a(); effect fn f() { let b = perform a(); fn ev(n) { if n == 0 { return b }; od(n - 1) }; fn od(n) { if n == 0 { return b + 1 }; ev(n - 1) }; to_string([ev(4), od(4)]) }; handle { f() } with a(k) { k(100) }
