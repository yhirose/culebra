# Allowlist for the suite-wide GAP5 gate (tools/difftest/leak_abort_suite.sh).
#
# Each non-comment line is an exact `_p(...)` case label that aborts under
# CULEBRA_GC_LEAK_ABORT=1 and is structurally out of reach of the current JIT
# ownership convention. The gate FAILS on any abort whose label is NOT listed
# here (a new regression); an allowlisted label that stops aborting is reported
# so this file can shrink. Blank lines and `#` comments are ignored. Regenerate
# the abort set with `just leak-abort-suite-update`, but keep the "why"
# comments by hand.
#
# The list is empty: no case in the corpus reaches teardown with an inflated
# refcount, reference cycles included. The last entry was a drop-object held
# through a hashable key's back-edge, whose residue used to read as inflated
# rather than as a keep; it stopped aborting and was removed. Anything that
# aborts now is a regression, and the gate reports it as one.
