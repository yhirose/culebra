# What the gate sweeps, and how much of it. tools/checks/check_gate_budget.sh
# holds each number exactly; growing one is fine and is done here, in the commit
# that grows it, with the reason in the message.
#
# Why these and not seconds: wall-clock on a loaded machine varies by 1.5-2x
# between runs of the same gate, so it cannot be a gate. The population is
# deterministic, and it is the half that actually moved — see the per-phase
# costs in the justfile's gate table for what one item is worth on each lane
# (one tests/*.cul file: 0.06 CPU seconds under --vm, 2.2 under --jit).
