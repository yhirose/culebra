# Ratchet for tools/checks/check_spec_examples.sh.
#
# Each line names a section of docs/language.md that states a rule and has no
# runnable ` ```culebra ` block — only prose, a table, or an example marked
# `# doctest: skip`, which runs nowhere. The key is `<chapter> > <section>`,
# or the chapter alone where it has no `###` sections of its own.
#
# The check FAILS on an unpinned section that is NOT listed here (a new rule
# with nothing executing it), and on a listed section that HAS since gained a
# runnable block (shrink the file — `--update` does it).
#
# Blank lines and `#` comments are ignored, and a key is the whole line. Put
# the reason for an entry in a comment *above* it, the way
# tools/difftest/leak_abort_allow.txt does.
#
# An entry is not a decision the way that file's are — it is a backlog item.
# A runnable block in the spec is the only check that lives in the same file
# as the rule it pins, and since the tree-walker retired
# (docs/essays/one-front-end.md) nothing else in the tree disagrees with the
# compiler on its own. This file should shrink. Some entries never will:
# lexical structure, grammar tables and CLI prose have nothing to execute.
