# 2026-11-12 Synth のエンベロープと再生（P4）

- 見込み: M。実際: `synth.cul` に約250行、テスト、docs の46節。ビルド2回。
- 内容: `perc`、ゲートつきの `adsr` と `.hold(secs)`（離した時点の値からリリース）、`control(name, init, lo, hi)`（同じ名前は同じ値）、`play(expr, wait = true, secs = nil)` と `SynthHandle`（`stop`、`playing`、`ends`、`now`、`set`、`render`）、自然な終わり（積は先に終わる因子、和は最後、遅延・弦・共鳴の余韻）。
- 計画からの変更: `g.stop(at)` をエンジンに足す代わりに、`Synth` が待たずに鳴らした Graph を持ち（参照を手放しても止まらない）、`secs` の時刻に出力の音量を0にし、終わったものを次の `play` で止めて手放す。オーディオスレッドに手を入れずに、鳴り方は同じ（その時刻から無音）。P11 の `Proxy` も同じ仕組みで旧い Graph を手放せる。依存に `Time` を足した。
- 見つけたこと: 鳴っている Graph に過去の時刻を指定した変更は、その場の時刻に回される（Graph の規則）。テストは未来の時刻で確かめる。`Handle.render` を足して、`set` の効き方を音のデバイスなしで確かめられるようにした。
- テスト: `tests/test_synth_play.cul`（VM と JIT で同じ）。変異18件すべてで落ちることを確かめた（hold の値と0秒の区間、自然な終わりの規則、フィルタの余韻、secs の無音、範囲の制限、名前の共有と食い違い、離さない adsr の拒否、set の時刻、Graph の検査が先）。
- /simplify: 重複5件（`Math.clamp`、`secs` の無音を式の層のエンベロープで表す、範囲の検査の関数、match の腕、`assert_throws`）と品質6件を採った。品質で効いたのは、鳴っている Graph の cancel は時計の位置へ回るのに set は指定の時刻のままなので、`at` なしの `set` が消えていたこと（テストが未来の時刻しか使っていなかった）。ほかに、`play` が Graph の検査より先に終わりを計算していた、`resonate([])`、高い q のフィルタの余韻、同じ名前の `control` の lo/hi の食い違い、0秒の区間での hold。`init` が `lo..hi` の外なのは、`lo > hi` と同じく拒むことにした。
