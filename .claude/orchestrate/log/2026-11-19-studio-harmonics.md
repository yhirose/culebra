# Synth Studio の倍音の棒グラフ（ce0d7f74、ca12456a）

- 規模：大（ページ、Playground と共有の実行の道、デスクトップの runner、試験。user の見た目の確認つき）。担当なし、独立レビュー1回、/simplify 2回。
- 仕様は user がお奨めどおりに選んだ：下の枠で Spectrum と Harmonics を切り替え、先に鳴らして解析は別の実行、音域 40〜2000 Hz、高さなしは「no pitch」。
- 計画のレビュー（12件すべて採用）が blocker を2つ見つけた：ブラウザに `Audio.decode` が無い、ビルドしたバイナリに `Sys` が無い。どちらもコードと試作で確かめてから計画を直した。
- 外れた見立て：レビューの試作は「`String` と `Math` は入る」としたが、ビルドしたバイナリでは `String` も入らなかった（試作のホストが自分で `String.pack` を名指していた）。前回（studio-desktop）と同じ種類の漏れで、前回の見張りは許す名前を試験に書き写していた。今回は試験が main.cul の `--with` を読んで照合する形にし、許す一覧を1か所にした。ビルドでしか出ない種類は、一覧を写さず元を読む見張りにする。
- user の指摘「タイムラグがある」：解析が音の長さに比例していた（wasm で音1秒あたり約0.15秒）。測ってから案を3つ出し、user が A（頭から倍々に区切る）を選んだ。前後10フレームの余白で区切りの値が全体と一致することを、実装の前に安い試作（chunks.cul）で確かめた。遅れは長さに依らず約0.1秒。
- /simplify は2回とも本物の状態の不具合を見つけた（解析中の Play で「ready」、解析中の Stop で「playing」、Stop 後の再生位置、区切りにしてから Stop で棒が消える）。区切りの導入は新しいロジックなので2回目を回したのは正しかった。
- 確かめ方：Chrome の拡張がつながらなかったので、ヘッドレスの Chrome を DevTools の口から動かした（scratchpad の cdp.mjs）。デスクトップ版は main.cul と同じページと runner を窓なしのサーバーで配り、同じスクリプトで確かめ、ビルドしたバイナリでも回した。
- 試験の時間：studio_test.mjs は約2.1秒（足す前と同程度）。runner の試験は 0.4秒。
- 見積もり約6時間（推定）、実績もほぼ同じ（タイムラグの直しの約1時間を含む）。
- just land はブランチ名が要る（`just land worktree-<topic>`）。引数なしで1回空振りした。
