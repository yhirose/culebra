# 2026-11-14 借りたメソッドの UAF（段階1・2）と trait の既定を演算子に

- 規模: 大（ランタイムの所有の規則を1つ足す。VM・JIT・標準ライブラリにまたがる）。user の承認：構造案（規則1・型1・キャストを数える検査・2段階）、drop の時機は「呼び出しが戻った直後」（条件はリークしないこと）。後半は /goal「3まで一気に」。
- 見込みと実績: 見込みは段階1に半日、段階2と trait の載せ直しに数時間。実績はおおむねそのとおり。重いのはビルド（dev の再ビルド 1 回約5分、リリースと ASan が各7分前後）で、テストは対象を絞った単発実行で回せた。
- 段階1（6495e3ea、ci/ 全ジョブ緑で着地）: JitHeldMethod（adopt/hold/lend）。`for` の iter()/dispose() を両レーン共通のランタイム関数に（JIT の compile_function_call_raw 約200行を削除）。カーソルの欄が閉包を所有。JIT の `__call__` は call_held の手前の関数を通す。キャストを数える検査。
- 段階2（e4dcb5a9）: 標準ライブラリが利用者のオブジェクトから読んだ関数を、呼び出しの中だけなら hold、呼び出しの外まで持つなら _jit_keep_closure（参照と pin、最後のコピーで手放す）で持つ。対象は Compress.zip、ワーカーの Dir、multipart の stream、Search の解析器、レスポンスの stream（手書きの同じ形を置き換え）。
- 段階3（b15df1c2 と Synth）: 前のセッションの trait のコミットを載せ直した。表が trait の既定で埋めた欄は bit で印を付けて hold し、JitCalleePin は外した。レビューの残り3件のうち、ワーカー終了時の順序と名前で引く道の表の利用を入れた。あいまいさの印を名前ごとにする件は、表があいまいなら名前で引く道に回るので外からは見えない潜在の穴で、直したが確認のテストは足していない（修正前に落ちないため）。
- 組み替えのきっかけ: (1) 構造案のレビューで、一時オブジェクトからの暗黙の変換が「文の終わりで参照を手放す」穴になる、wasm で C++ のローカルだけが持つ関数を rooted で呼ぶと回収される、と分かり型と呼び方を決めた。(2) 実装後の独立レビューで、assert レーンの lend の確認（refcount>1）が「メソッドの中で最後のインスタンスが手放される」正当なプログラムで落ちると分かり撤回した。その形を ASan で VM/JIT・GC stress あり/なしに回し、use-after-free が無いことを確かめた。(3) 足したテストの1つは古い trait のビルド（JitCalleePin あり）でも通ったので、表の欄を lend に戻す変異で落ちることを確かめた。
- 再レビュー（user の求め）: 段階2と trait に3観点の独立レビュー。退行4件（Search の hook を pin で持つため持ち主との循環が回収されない、あいまいな既定のエラー位置が前の文、`__call__` があいまいだと型の判定が投げる、ワーカーが呼ばない既定まで組み立てる）と、仕様の判断3件（名前の組で優先、あいまいでも型の判定は true、等しさの組に hash）を直した。Search はハンドルの `_keep` 欄（回収器がたどる辺）に、既定の表は Peek と名前ごとの `by_name`、有無の問いは投げない。meta を封じる assert を足した。
- 見込みと実績（再レビュー以降）: 見込みは半日、実績は1日超。計画のレビュー、実装のレビューのたびに修正前からある同種の穴（遅延の連鎖の再入、`chunk_by`、Http.server の pin、ワーカーの後始末）が見つかり、それを束に取り込み続けた。再入の直しは自分で新しい segfault を入れた。user と相談して束を絞り、修正前からある穴は外して記録した。根本原因（ネイティブのコードが参照を持たない生のポインタを握ったまま利用者のコードを呼び返す、解放だけで drop が走る）は別の仕事にする。
- 気づき: 敵対的レビューは、修正前からある同じ種類の穴をいくらでも見つける。束に入れるのはこの束が入れた退行だけにし、修正前からある穴は記録して別件にする。新しい穴が2周続いた時点で止めて相談するべきだった。
- 気づき: 「このテストは修正前に落ちるか」を、修正前のバイナリで1件ずつ単独に回して確かめると、テストの書き間違い（`zip` の要素の形、`Dir.zip` の引数、オブジェクトの欄の `mut`）も同時に見つかる。最初の1件で segfault すると後ろの確認が見えないので、1件ずつのファイルに切り出す形が安い。
