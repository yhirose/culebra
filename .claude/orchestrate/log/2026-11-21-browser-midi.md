# ブラウザの MIDI と、管楽器のコントローラーで弾くシンセリードの例（FM Synth をブラウザで、段階2）

- 規模: 大（直列、担当なし。/simplify の3人だけ並列）。着地 ba147cca＋ba172461＋ff1a2fb8（ci/ で全28ジョブ緑、着地の時に master が1つ進んでいて rebase、`just test-dev` を通して早送り）。
- 見込みと実績: cpp-midilib のホスト用バックエンド（別リポジトリ、3 OS の CI 緑）、MIDI の扱いをネイティブとブラウザで共有、ページの Web MIDI、JSPI 版の Time.sleep が制御を返す。おおむね見込みどおり。dev の作り直しは rebase 後の1回、Playground の wasm は2回。
- 守備範囲の外で回したもの: なし。`just check` の1回目は sandbox が FSEvents を拒んで `tests/test_fs_watch.cul` が落ち、sandbox の外で回し直して緑（既知）。
- /simplify の指摘で入れたもの: JSPI の EM_ASYNC_JS を二重に包んでいた、sysex の許可を取り直すと古い MIDIAccess の受け口が残り同じメッセージが2回届く、sysex の許可が無いのに送ったことになる、断った許可が次の実行で聞き直されない（MidiGrant を実行ごとにリセット）。
- user の決定: ブラウザの Time.sleep は短い眠りが 4 ms に切り上がるがそのまま（段階3は「画面か MIDI のどちらかが届くまで待つ」形で避ける）。
- 範囲の変化: 実機の確認が通った後、user が例（Audio の「EWI: Synth Lead」）を求め、音色を耳で6回詰めた。うち2回は測って原因を突き止めた。「重なったきらきら／うょうょ」は少しずらしたノコギリ波のうなりで、100 ms ごとの音量の最大÷最小が 1.33 → 1.02（ずらしをやめ、ちょうど1オクターブ下の波で太くした）。「テンッ」は吹き始めにフィルタを一瞬開くアクセントだった。
- 新しい問題: Synth の部品で `2.0 - breath` が実行時に TypeError（数が左の非可換演算は反転しない、言語の決まり）で、lint では見えない。user が言語に右側の演算子（`__rsub__` 等）を足すと決め、別の仕事にした（計画はメモリ）。
- スキルへの気づき: 音色の調整は user の耳が最終の判定だが、「揺れる」「混じる」のような訴えは、レンダーして数値（区間ごとの RMS など）で原因を切り分けてから直すと、1回で当たる。
