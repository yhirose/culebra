# 2026-11-19 test_synth_play の過ぎた時刻の傾き（小）

- きっかけ: synth-play-clock の確認で、文ごとに眠りを挟む写しが変更前の 115 行（`set(..., at: 0.0, secs: 0.5)` の後に `now()` を読み直して 0.25 秒後の音高を見る）で落ちた。set と now の間が約 15 ms 延びると 20 Hz の許容を外れる。CI では未観測。
- 直し方: set の前後で時計を読み、傾きの始まりがその間にあることから音高の上下の端を出す（d65737ac）。`set` の戻り値（傾きの終わり）は文書にないので使わなかった。
- 確認: 直した版は vm/jit/gc-stress＋refs/眠りの写しで緑。変異「傾き2倍」で assert_lt、変異「at: 0.0 だけ 0 から動く」で assert_gt が落ちる。最初の変異（過ぎた時刻を一律にいまへ寄せない）は前の 111 行で先に落ち、新しい確認を隠したので、範囲を絞った変異を作り直した。assert_gt の変異での余裕は約 23 Hz（507 対 530）で、set の前後の読みの間が延びるほど効きは弱まる（偽の失敗にはならない）。
- 見積もり 30〜40 分、実績約 45 分（プリアンブルの焼き込みのため変異ごとに `just dev`、計6回）。
- 気づき: 変異で確認の効き目を見るときは、変異が新しい確認だけに届くよう範囲を絞る。広い変異は前の確認で先に落ちて何も示さない。
