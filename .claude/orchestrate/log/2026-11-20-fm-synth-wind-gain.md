# 2026-11-20 examples/fm-synth の EWI の音量（小）

- 作業: 1つの `CARRIER_GAIN`（0.25、鍵盤の和音のための余裕）を `KEYS_GAIN` 0.6 と `WIND_GAIN` 1.5 に分けた（1d0c8027）。鍵盤の1音の検査は、リミッターに届く音量をかけた値で測る形に直した。
- 見込み 30分、実績は約1時間半。延びたのは、user が実機で吹いて「まだ小さい」と返した後の原因探しの往復。
- 組み替え: 「EWI が小さい」に、最初はゲインで応え（1.5 → 2.5）、それでも小さいと言われた。根は EWI USB 本体の breath-gain 20 で、普段の息が 0.45 前後にしか届いていなかった（memory に `kauai live` での実測が残っていた）。`kauai live` も同じく小さいと user が確かめ、breath-gain を出荷時の 64 にして両方ちょうどよくなった。ゲインは `kauai live` の全開の RMS（約 -6 dBFS）に揃う 1.5 に戻した。
- 気づき: 入力の機器に比例して鳴る音が小さいとき、アプリのゲインを上げる前に、入力の値がどこまで届いているか（画面のメーター、memory の実測、機器の設定）を先に見る。今回は memory に答えがあったのに、2周目まで引かなかった。
- 後処理: fm-synth の2つのテスト（executor と `--jit`）、レベルの測定（Synth.render、プリセット10個）、/simplify は1担当で指摘1件（採用）。
