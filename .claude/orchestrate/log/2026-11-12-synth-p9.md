# 2026-11-12 Synth P9: 新しい音源と数式の部品

- 規模: 大（エンジンと式の層、計画 → 独立レビュー → user の確認 → 実装）。コミットは1つ（docs の同じファイルに両方の節が入るので、計画の2つには分けなかった）。
- 見込みと実績: 見込み半日弱、dev のビルド2〜3回。実績は dev 5回（最初の1回は編集の途中の木を拾った、1回は変異を環境変数で切り替える版、1回は /simplify の後）。1回は避けられた: 編集の前にビルドを始めない。
- 計画のレビューで変えたこと: `.decay2` のループ版は、係数がレートで決まり式はレートを知らないので成り立たない（測る前に構造で落ちた）。一極の部品は Lag と Decay の2つの小さな型にし、Decay2 は式の層で差を取る（ビット単位で一致）。種類の表（値の数、取り込むか、値の範囲）は default をやめて列挙し、ベンチの -Werror で足し忘れが落ちる。
- user が決めたこと: 種は種類（ストリーム）とチャンネルでずらす、impulse の phase は周期の割合、Voices の freq は声の最初のノートから。
- テストの効き目: エンジン15、Synth 23 の変異がすべて落ちる。エンジンの変異は `P9_MUT` で切り替える版を1回だけビルドして回した（変異ごとのビルドを避ける形として使える）。
- テスト時間: 2ファイルとも VM 0.06 s、JIT 3.3 s と 3.2 s。`just check` 29 s（予算 23 s を超えているが、この変更の前から同じ）。
- ベンチ（`just bench-audio-graph master`）: 既存の7グラフはサンプルが同じ、時間の差は -2.1〜+1.8%（揺れの範囲）。新しいグラフ sources は 77 ns/サンプル。
- /simplify: 種類の名前を引く表の関数（エラー文を表から作る）、`work` の同形のループをラムダに、`{...options, seed: …}`、pulse の何もしない部品を省く、docs とコメントの食い違い4件（cubic は ±1 を超えない、freq 0 は phase 0 のときだけ、pulse の width はエンベロープを取らない、-Wswitch はベンチの検査で落ちる）。採らなかったもの: exprange の部品を減らす案（丸めが変わり、定義式と一致しなくなる）。
