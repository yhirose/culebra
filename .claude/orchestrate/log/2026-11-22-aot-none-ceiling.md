# AOT none の大きさの上限（2026-11-22）

- 規模: 小。master の CI（test-ubuntu (aot)、linux-llama）が `check_aot_feature_axes` の none の上限で赤。
- 切り分け: CI のログから none の実測を引くと、46cfd52b で 474,416（上限まで24バイト）、af6d1566 から 478,512。差はちょうど1ページ（4,096）で、間に入った runtime の変更は機能（d5fea8f6、f342cd4f）だけ。手元でコミットごとに測るのは Linux x86-64 のビルドが要るのでやめた。
- 判断（user）: 6030c7f0 と同じ決め方で、実測 + 16 KiB（494,896）に上げる。
- 気づき: 上限は10月30日から3週間で16 KiB を使い切った。ページ単位で動くので、越えるのは最後の小さな変更で、その変更が犯人とは限らない。CI のログの「none is N bytes」で余りを見ておけば、越える前に分かる。
