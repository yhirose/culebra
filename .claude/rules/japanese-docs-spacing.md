- **日本語 docs（`docs/*.ja.md`、`docs/essays/*.ja.md`、`docs/guides/*.ja.md`）は半角英数字（a-z/A-Z/0-9、コードスパンの``` ` ```境界含む）と日本語が直接隣接する箇所に半角スペースを入れない**（`15 年`ではなく`15年`、`culebra の`ではなく`culebraの`、`API を`ではなく`APIを`、`` `ok` フラグ ``ではなく`` `ok`フラグ ``）。以下はそのまま変更しない: ①英単語同士のスペース（`thread / lock / monitor`）②`+`/`/`/`→`等の記号と日本語の間のスペース（`AST + インタプリタ`、`Go / Rust 系`）③コードブロック・インラインコードの中身 ④句点・コロン直後の英語文への遷移（`2009. 494 pages...`）⑤ **見出し行（`#`〜`######`）— GitHub のスラグ生成は見出しテキスト中のスペースをハイフンに変換して `id` にするため、見出しのスペースを消すと目次・相互参照の `#anchor` リンクが壊れる**。見出しを参照する `[text](#anchor)` 形式のリンクテキストも見出しと表記を合わせるため対象外。コード内コメントの日本語文言にも同じ規則を適用してよいが、doctest で実行されるコードブロックは文字列リテラルの意図しない改変を避けるため触らない。機械的に全ファイル適用する際は fenced code block 除外・見出し行除外・アンカーリンクテキスト保護の3点を実装したスクリプトを使い、適用後に `just doctest` と見出しスラグ⇔`#anchor`リンクの突き合わせで検証する。
- **日本語同士の間の空白は英数字境界と別ルールで、機械的に一括処理しない。** 唯一の例外＝**句点「。」・読点「、」の直後**に続く日本語文字の前のスペースは常に不要なので削除する（`〜します。 次は`ではなく`〜します。次は`）。それ以外（カタカナ複合語の分断 `クラス インスタンス`→`クラスインスタンス`、単純な誤字混入 `または スコープ`→`またはスコープ`、書誌の人名リスト＋「訳」のような意図的な区切り `鈴木幸敏 訳`＝残す）は文脈判断が要るので1件ずつ確認してから直す。
