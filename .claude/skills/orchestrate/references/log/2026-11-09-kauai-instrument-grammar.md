# Kauai: one grammar for voices and drums (2026-11-09)

- 規模: 大(1領域だが、書式の破壊的変更。曲、docs 英日、テスト、wasm まで)。担当なしで直列。
- 見積もり: 実装を Audio.Graph の段階1+2 と同程度。実績: 設計の合意(案の比較、試作、書式の確定)が実装の数倍。実装は約半日、ビルドは `just dev` を約6回(各約4.5分)、`just site-build` を2回。
- 効いたこと: 変更前のバイナリを先に保存し、全 .kau のイベント列を旧新で完全比較(23曲一致)。一回限りの変換ツール(Python)は repo に入れず、桁そろえまで入れて diff を小さくした。
- 外れ: (1) `just dev` を背景で回したのに、古いログを読んで完了と取り違えた(通知を待つべき)。(2) 局所変数 `instrument` が同名の関数を隠し、焼き込みで異常終了(`just dev` の末尾で初めて分かる。preamble の編集は名前の衝突を grep してから)。(3) 簡素化の指摘で、つまみを Object にすると `keys` という名前が `keys()` と衝突する実バグが見つかった。user の入力が名前になる表は配列にする。
- 守備範囲の外で回した後処理: `just site-build`(wasm の作り直し)。変更が preamble の文法なので、コミットした wasm が古いと CI の check-playground が落ちるため。
- 組み替えのきっかけ: user の「案2が難しいなら、もっと良い方法を」(案の再検討)、「構成図を戻して」(Artifact の取り違え)、「`vol <NUM>` と `key=val` が混ざる」(線引きの追加)。
- スキルへの気づき: 設計メモ(Artifact)を直す依頼は、全面書き直しの前に、消すものと残すものを一言確認する(旧構成図を消して戻す手戻りがあった)。
