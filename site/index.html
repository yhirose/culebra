culebra

A dynamically-typed cross-platform scripting language that runs three ways from one source: an interpreter, an LLVM JIT, and native binaries.

Open the Playground → Get started
example.cul 
let people = [
  { name: 'Taro', age: 30 },
  { name: 'John', age: 45 },
  { name: 'Ada',  age: 36 },
]

for p in people.sorted_by(|p| p.age) {
  println("{p.name} is {p.age} years old")
}

Three backends, one language

The same program yields identical results and errors under the interpreter, JIT, and AOT.

Runs in the browser

The interpreter compiles to WebAssembly, so the Playground executes entirely client-side.

Batteries included

Strings, collections, tensors, regex, JSON/TOML, HTTP, and more in the standard library.

One executable

The stdlib, test runner, linter, formatter, debugger and docs are all in the same binary. Nothing else to install.
