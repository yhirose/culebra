culebra

A programming language that runs three ways from one source: a tree-walking interpreter, an LLVM JIT, and native ahead-of-time binaries.

Open the Playground → Repository 
# runs in your browser on the Playground — interpreter compiled to WebAssembly
fn fib(n) { if n < 2 { n } else { fib(n-1) + fib(n-2) } }

let xs = [1, 2, 3, 4, 5]
puts("squares: " + xs.map(|x| x * x).to_string())
puts("fib(20): " + fib(20).to_string())

Three backends, one language

The same program yields identical results and errors under the interpreter, JIT, and AOT.

Runs in the browser

The interpreter compiles to WebAssembly, so the Playground executes entirely client-side.

Batteries included

Strings, collections, tensors, regex, JSON/TOML, HTTP, and more in the standard library.
