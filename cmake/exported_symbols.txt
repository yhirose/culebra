# The symbols culebra publishes in the executable's symbol table. An ld version
# script, so ELF takes it as-is; the Windows build reads the globs out of it to
# generate a PE .def (cmake/gen_pe_exports.cmake), which is why every entry has
# to stay a plain prefix glob.
#
# ORC JIT resolves what it emits references to through
# DynamicLibrarySearchGenerator, which is dlsym over the process, so every name
# it can ask for has to be visible here. Those names are exactly culebra's
# C-linkage ones: the `culebra_runtime_*` helpers (rt_mem.inc.h's rt:: family) and
# the `culebra_g_wake` interrupt flag (jit.h's getOrInsertGlobal). The C++ EH
# entry points JIT'd landingpads reference (__cxa_throw, __gxx_personality_v0)
# come from libstdc++.so and are found there, not in this table.
#
# Why a whitelist rather than -rdynamic: see culebra_export_jit_symbols() in
# CMakeLists.txt.
{
  culebra_*;
};
